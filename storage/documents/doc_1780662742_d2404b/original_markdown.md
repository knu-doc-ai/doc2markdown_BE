데이터 분리: 훈련 데이터(학습), 검증 데이터(모델 검증), 테스트 데이터(미지 데이터 최종 평가).

1. 리스트와 넘파이 (NumPy) 리스트 vs 넘파이 list * 2 = [1 2 1 2] / numpy * 2 = [2 4] 리스트는 2차원 X

2. 판다스 (Pandas) set_index[‘도시’], inplace = True: 도시를 index로 설 정(inplace = True) 해야지 원본이 바뀐다. 데이터 읽기: df.연도, df['연도'], 행 슬라이싱 (0:2). drop([‘연도’],1): 연도 없애기

3. 데이터 분석 이유 및 용어 분석 이유: 설명, 예측, 추천.

입력값 (X): 독립변수, 피처 (예: 몸무게, 나이). 결과값 (Y): 종속변수, 라벨, 정답, 타겟 (예: 고혈압).

4. 데이터 분석 유형 지도 학습: 입력과 결과가 모두 존재. 예측 후 시간이 지 나면 정답 확인 가능.

회기 – 연속적인 값 예측(온도, 주가..) y = ax +b 분류 – 어떤 그룹에 속하는지 구별 (T/F, 등급) ax + by + c > 0 비지도 학습: 입력만 존재, 결과 X 패턴이나 특성 발견 클러스터링: 비슷한 데이터를 집단으로 묶음(K-means..) 강화학습: 정답은 있지만 알려주지 않고 보상으로 방향성 제공

5. 탐색적 분석(EDA) 수집한 데이터의 전체적인 특성을 분석 이상치 (Outlier): IQR (Q3 - Q1)을 기준으로 1.5배 떨어 진 하한/상한 펜스 밖에 있는 데이터.

6. 데이터 전처리 (Data Preprocessing) 데이터 전처리 데이터 분석 성능 향상, 형태 변형 결측값 처리: dropNA() - 버리기, fillna() - 대체 , 분석 단계로 넘기기 오류값 처리: 버리거나 대체 이상치 처리: IQR 계산 기준

범주형 변수 처리 원핫 인코딩: 한 개만 1, 나머지는 0 (get_dummies()) 스케일링:단위/기준이 다른 데이터를 동일 기준으로 조정 표준 스케일링: 평균 0, 표준편차 1로 조정. 최소-최대 스케일링: 최소 0, 최대 1로 조정.

최근에는 훈련/검증 데이터로 바로 진행하는 경우가 많 음.

모델: 수학식 (구조와 파라미터).

학습 과정: 모델 학습 → 예측 → 손실 확인 → 손실 감 소 방향으로 반복 → 모델 확정 → 성능 평가.

# 8. 군집화 (Clustering) 상세

목적: 비슷한 특성을 가진 데이터 집단으로 묶기 (비지도 학습).

유사도 측정:

유클리드 거리 (Euclidean Distance): 절대적 거리값.

코사인 유사도 (Cosine Similarity): 방향 유사성 (텍스트 분석 등에 활용).

자카드 유사도 (Jaccard Similarity): 공통 부분을 고려 한 상대적 유사성 (영화/책/음악 추천에 활용).

클러스터의 수 (K): 그룹의 개수 설정이 중요. (K값이 너 무 작거나 크면 문제 발생).

군집화 알고리즘:

K-평균 (K-Means): 임의의 중심점 설정 → 거리 측정 → 중심점 이동 반복 → 최적의 평균값 찾으면 종료. DB스캔 (DBSCAN): 밀도 기반 클러스터링 (달 모양 데이 터 등에 적합).
